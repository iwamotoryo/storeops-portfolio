# ドッグサロン向け 予約・ペット管理・ホテル予約システム

> 本ドキュメントは、実案件を匿名化・一般化したケーススタディです。実在する飼い主名・電話番号・ペット名・LINE ID は一切含めていません。

## 概要

ドッグサロン（トリミングサロン）向けに、飼い主とペットの情報管理、トリミング予約、ペットホテル予約までを扱う店舗運営システムです。1人の飼い主が複数のペットを連れてくる、犬種やコースによって料金や所要時間が変わる、といったペット業界特有の業務をデータ構造として整理しました。

## 背景

ドッグサロンでは、予約のたびに「どの飼い主の、どのペットが、どのコースを受けるか」を正確に把握する必要があります。さらに犬種・体格・性格によって所要時間や注意点が変わり、トリミングだけでなくペットホテルの宿泊予約も扱う店舗が多くあります。こうした情報が紙や個別のメモに分散していると、確認や引き継ぎに手間がかかっていました。

## 現場課題

- 1人の飼い主が複数のペットを持つため、人とペットの関係を正しく管理する必要がある
- 犬種・コース・オプションによって料金と所要時間が変わり、見積もりや予約枠の計算が煩雑
- トリミング予約とホテル予約を別々に管理しており、二重管理になっていた
- ペットごとの注意点（持病・苦手な施術・性格など）を引き継ぎにくい
- 連絡や次回予約の案内を手作業で行っており、負担が大きい

## 解決方針

- **飼い主とペットを分けて管理**し、1対多の関係をデータ構造で正しく表現する
- 犬種・コース・オプションを**マスタとして管理**し、料金と所要時間を自動で算出する
- トリミング予約とホテル予約を**同じシステム内で扱い**、二重管理をなくす
- LINE連携を前提とした構成にし、将来的に飼い主自身が予約・確認できる導線を見据える

## 主な機能

### 飼い主管理
- 飼い主の基本情報・連絡先の管理
- 1人の飼い主に複数のペットを紐づけ

### ペット管理
- ペットの基本情報（犬種、体格、性格、施術上の注意点など）
- 飼い主との関連付け、施術履歴の記録

### 予約管理
- トリミング予約の登録・変更・キャンセル
- コース・オプション・担当者を考慮した予約枠管理

### コース管理
- 提供コースの定義と料金設定
- コースごとの標準所要時間の管理

### 犬種管理
- 犬種マスタの管理
- 犬種・サイズによる料金・所要時間の調整に利用

### ホテル予約
- ペットホテルの宿泊予約（チェックイン・チェックアウト日）
- 宿泊期間に応じた料金計算

### オプション料金管理
- 追加オプション（爪切り、歯磨きなど）の料金管理
- 予約への加算と合計金額の自動計算

### LINEログイン構想
- 飼い主がLINEアカウントでログインし、予約状況を確認できる仕組みの構想
- 友だち登録を起点とした連絡導線の設計

### ポイント連携構想
- 来店・利用に応じたポイント付与・利用の構想
- リピート促進を目的とした設計の検討

## 使用技術

- バックエンド：FastAPI / Python
- データベース：PostgreSQL
- インフラ：Docker / Nginx / Linux（VPS）
- 外部連携：LINE（ログイン・連絡導線の構想）
- バージョン管理：Git / GitHub

## 工夫した点

- **飼い主とペットを分離**し、1人が複数のペットを持つ実態を自然に表現できるようにした
- 犬種・コース・オプションをマスタ化し、**料金と所要時間の計算を自動化**して見積もりミスを減らした
- トリミングとホテルを同一システムで扱い、**予約の二重管理を解消**した
- ペットごとの注意点を記録し、**担当者が変わっても引き継げる**ようにした
- LINE連携・ポイント連携を見据え、**将来の拡張を妨げないデータ構造**を意識した

## セキュリティ・個人情報への配慮

- 飼い主の連絡先は個人情報として扱い、ログインと権限管理でアクセスを制限
- LINE連携で扱う識別子やトークンは、シークレットとして安全に管理し公開しない
- 通信はHTTPSで暗号化
- 本ポートフォリオには、**実在する飼い主名・電話番号・ペット名・LINE ID は一切記載していません**
