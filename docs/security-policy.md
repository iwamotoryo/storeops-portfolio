# セキュリティ方針

本ポートフォリオは「実績はあるが、本番情報は公開しない」という方針を徹底しています。実店舗の業務システムは、顧客の個人情報や売上といった機微な情報を扱うため、公開資料の作成にあたっては以下のルールを必ず守ります。

## 公開しないもの（厳守事項）

以下は、いかなる場合も公開リポジトリに含めません。

- **本番コードを公開しない**
  本番システムのソースコードはコピー・転載しません。本リポジトリには、考え方・設計・担当範囲を説明する資料のみを置きます。

- **本番DBを公開しない**
  本番データベースのスキーマ実物・実データ・ダンプファイルは含めません。掲載するのは一般化した設計例のみです。

- **`.env` を公開しない**
  環境変数ファイル（`.env`、`.env.*`）は作成・公開しません。`.gitignore` で除外しています。

- **APIキーを公開しない**
  外部サービスのAPIキー・トークン・認証情報は記載しません。

- **LINE Secret を公開しない**
  LINE の Channel Secret・アクセストークンなどのシークレットは記載しません。

- **顧客情報を公開しない**
  氏名・電話番号・住所・メールアドレス・LINE ID・免許証情報などの個人情報は、実在するものを一切記載しません。

- **売上の生データを公開しない**
  売上の実数値・明細などの生データは記載しません。資料に数値を用いる場合も、匿名化・一般化したもののみとします。

- **管理画面URLを公開しない**
  本番の管理画面URL・本番ドメイン・内部URL・サーバ情報は記載しません。

## スクリーンショットの取り扱い

- スクリーンショットは**匿名化したものだけ**を掲載します。
- 氏名・電話番号・住所・メールアドレス・LINE ID・予約番号・契約情報・売上の生データ・URL・サーバ情報が写り込んだ画像は掲載しません。
- 必要に応じてマスキング・ダミーデータへの差し替えを行ったうえで掲載します。

## デモ環境を作る場合の方針

実際に動く画面を見せるためにデモ環境を用意する場合は、以下を守ります。

- **本番環境と完全に分離する**
  本番のコード・DB・認証情報・ドメインとは一切共有しない、独立した環境として構築します。
- **本番データを使わない**
  デモには、匿名化したダミーデータのみを投入します。
- **外部に影響する機能を無効化する**
  デモ環境では、以下のように外部・実害につながる機能を無効化します。
  - メール送信を無効化
  - LINE送信（通知・メッセージ）を無効化
  - 決済を無効化
  - CSV出力など、データ持ち出しにつながる機能を無効化

## リポジトリでの技術的な対策

- `.env` などのシークレットは `.gitignore` で除外（[.gitignore](../.gitignore) 参照）
- DBダンプ・ログ・証明書・鍵ファイル（`*.dump`、`*.log`、`*.pem`、`*.key` など）もコミット対象外
- 公開前に、個人情報・シークレット・本番URLが含まれていないかを確認

## 基本姿勢

セキュリティと個人情報保護は、機能の追加よりも優先します。「公開して良いか少しでも迷うものは公開しない」を原則とし、実績の説明は匿名化・一般化した範囲で行います。

## Public公開前チェックリスト

リポジトリやスクリーンショットを公開・更新する前に、毎回このチェックリストを確認します。**1つでも該当する場合は公開しません。**

- [ ] 本番コードが含まれていない
- [ ] `.env` が含まれていない
- [ ] APIキー・トークン・Secret が含まれていない
- [ ] 本番URL・管理画面URLが含まれていない
- [ ] IPアドレスが含まれていない
- [ ] 顧客名・電話番号・住所・メールアドレスが含まれていない
- [ ] LINE ID・免許証情報・契約情報が含まれていない
- [ ] 売上の生データが含まれていない
- [ ] スクリーンショットに個人情報が写っていない
- [ ] 技術スタックや担当範囲を過度に盛っていない
